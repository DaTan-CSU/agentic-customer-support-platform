# 使用指南

这份指南带你走完一个中文电商客服会话：先查询订单和物流，再提交退款申请，最后查看人工审批与 Trace。

## 启动项目

1. 按根目录 [README](../README.md) 配置文本模型并启动前后端。
2. 打开 [http://localhost:3000](http://localhost:3000)。
3. 从会话菜单新建一个会话。

## 查询订单和物流

在输入框发送：

```text
帮我查一下订单 DMO20260101 的订单信息和物流。
```

分诊客服会识别出订单和物流两个意图，并调用对应专员。回复中应包含订单商品、金额、物流状态和签收信息。

## 提交退款申请

继续发送：

```text
我要申请退款142.8元，原因是尺码不合适。
```

售后专员会调用退款工具并暂停在人工审批节点。打开审批面板，检查订单号、金额和原因，然后点击 `Approve`。

批准后，会话恢复执行并返回模拟退款结果。助手不会在批准前把退款说成已经完成。

## 查看 Agent 和 Trace

- 查看 Agent 面板，确认当前分诊和专员流转。
- 查看工具调用，核对订单查询、物流查询和退款申请的参数与返回值。
- 展开 Trace，查看本次运行的 Agent、工具和审批节点。
- 查看会话摘要，确认意图、订单号和后续处理状态。

## 其他可用场景

可以换用以下订单号观察不同业务状态：

| 订单号 | 场景 |
|---|---|
| `DMO20260102` | 物流延迟 |
| `DMO20260103` | 退货处理中 |
| `DMO20260107` | 换货处理中 |
| `DMO20260110` | 价保处理中 |

如果模型要求补充订单号、金额或原因，按页面提示继续输入。最终结果以工具返回和审批状态为准。
