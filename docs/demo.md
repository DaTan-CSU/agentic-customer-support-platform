# 订单、退款与人工审批演示

这份脚本用于启动项目后的现场演示或录屏。使用仓库固定订单数据，模型回复以实际运行结果为准。

## 准备

1. 按根目录 README 启动前后端，在 `.env` 或进程环境中填写文本模型服务配置。
2. 打开 `http://localhost:3000`，从 ChatKit 的会话菜单新建会话。
3. 保留左侧 Agent View 和右侧 Customer View，让观众同时看到用户问题、工具调用与审批。

## 建议录制 60–90 秒

| 阶段 | 操作 | 展示重点 |
|---|---|---|
| 订单与物流 | 输入“帮我查一下订单 DMO20260101 的订单信息和物流。” | 分诊调用订单及物流专员，汇总商品、金额和物流结果 |
| 退款申请 | 输入“我要申请退款142.8元，原因是尺码不合适。” | 售后请求触发审批，助手暂停等待人工决定 |
| 人工批准 | 展开左侧 Pending Approvals，核对订单号和金额，点击 Approve | 审批状态更新，会话恢复，返回模拟退款结果 |
| 过程追踪 | 展开调用链和 Runner Output | 查看实际 Agent、工具调用与执行状态 |

订单 `DMO20260101` 的固定金额是 **142.8 元**，商品是“361°男子运动套装 2024春季速干透气”，物流记录为已签收。订单日期来自历史 fixture。

若模型要求补充信息，按真实提示继续操作；不要剪成未发生的自动闭环。录制前确认 Trace 和审批内容与当前会话对应。

## 解说示例

“这是从 OpenAI 客服示例扩展的中文电商工作流。复合问题通过专员工具协作处理；退款使用 SDK 原生人工审批，批准后才恢复执行。左侧可以查看工具调用与 Trace。订单、退款和业务接口数据为模拟，编排、模型请求、审批控制以及本地追踪是真实执行。”
